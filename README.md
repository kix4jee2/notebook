# Notebook

OneNote 스타일의 개인용 노트 앱. **`notebook.html` 파일 하나**가 전부다.
설치·서버·계정·인터넷 연결이 필요 없다.

## 사용법

`notebook.html` 을 더블클릭해 브라우저(Chrome, Edge, Firefox)로 연다.

```
┌──────────┬───────────────┬──────────────────────┐
│ 폴더      │ 노트 목록      │ 편집 │ 미리보기        │
└──────────┴───────────────┴──────────────────────┘
```

- **왼쪽**: ⭐ 즐겨찾기 · 폴더 · 태그. `＋ 새 폴더` 로 추가하고, 항목 위의 `⋯` 에서 이름 변경·삭제.
- **가운데**: 선택한 항목의 노트. 노트를 왼쪽 폴더로 **드래그하면 이동**한다.
- **오른쪽**: 마크다운으로 쓰면 옆에서 바로 렌더링된다. 입력이 멈추면 자동 저장.
- 노트 제목은 본문의 첫 `# 제목` 줄에서 자동으로 뽑는다.

## 즐겨찾기와 태그

- **즐겨찾기**: 노트 목록에서 `☆` 를 누르거나 `Ctrl+D`. 즐겨찾기한 노트는 폴더 안에서 항상
  맨 위에 오고, 왼쪽 맨 위의 **⭐ 즐겨찾기** 에서 폴더와 상관없이 모아 볼 수 있다.
- **태그**: 편집기 위의 태그 줄에서 추가한다 (`Ctrl+G` 로 바로 입력). 쉼표로 여러 개를 한 번에
  넣을 수 있고, 이미 쓴 태그는 자동완성된다. 빈 입력에서 `Backspace` 를 누르면 마지막 태그가 지워진다.
- 왼쪽 **태그** 목록에서 태그를 고르면 그 태그가 붙은 노트만 폴더를 가로질러 모인다.
  그 상태에서 만든 새 노트에는 해당 태그가 자동으로 붙는다.
- 태그 옆 `⋯` 에서 **이름 변경**(모든 노트에 일괄 반영) 또는 **모든 노트에서 제거**.
- 검색은 본문·제목뿐 아니라 **태그 이름도** 함께 찾는다.

## 단축키

| 키 | 동작 |
| --- | --- |
| `Ctrl+F` | 모든 폴더·노트 전문 검색 |
| `Ctrl+E` | 새 노트 |
| `Ctrl+S` | 즉시 저장 (평소엔 자동 저장) |
| `Ctrl+P` | 미리보기 / 분할 전환 |
| `Ctrl+D` | 즐겨찾기 토글 |
| `Ctrl+G` | 태그 입력으로 이동 |
| `Ctrl+B` `Ctrl+I` `Ctrl+K` | 굵게 / 기울임 / 링크 |
| `Tab` `Shift+Tab` | 들여쓰기 / 내어쓰기 |
| `Ctrl+V` | 클립보드 이미지 삽입 |
| `Esc` | 검색 해제 |

목록에서 `Enter` 를 누르면 다음 항목이 자동으로 이어지고, 빈 항목에서 한 번 더 누르면 끝난다.

## 지원하는 마크다운

제목 `#`~`######`, **굵게**, *기울임*, ~~취소선~~, `인라인 코드`, 코드 블록(``` ```),
인용 `>`, 순서/비순서 목록(중첩 가능), 체크박스 `- [ ]`(미리보기에서 클릭해 토글),
링크, 이미지, 표, 수평선 `---`.

## 이미지

본문에 **Ctrl+V 로 붙여넣거나** 파일을 **끌어다 놓으면** 삽입된다.
이미지 원본은 노트 본문과 분리해 `images` 스토어에 보관하고, 본문에는 `![](img:<id>)`
참조만 남는다 (base64로 본문이 비대해지는 것을 막기 위해서다). 화면에 그릴 때만
`URL.createObjectURL()` 로 임시 `blob:` 주소를 만들어 쓴다.
어떤 노트에서도 참조하지 않게 된 이미지는 노트 삭제 시 함께 정리된다.

## 데이터가 저장되는 곳

브라우저의 IndexedDB 안, `notebook` 데이터베이스 하나에 스토어 3개로 나뉜다.

```
notebook (IndexedDB)
├─ folders : { id, name, order, createdAt }
├─ notes   : { id, folderId, body, title, pinned, tags[], createdAt, updatedAt }
└─ images  : { id, blob, type, createdAt }
```

선택 중인 폴더·노트, 테마, 열 너비 같은 설정만 localStorage(`notebook.settings`)에 들어간다.

물리적으로는 브라우저 프로필 폴더에 있다. Windows Chrome 기준:

```
%LOCALAPPDATA%\Google\Chrome\User Data\Default\IndexedDB\
  file__0.indexeddb.leveldb / .blob              ← file:// 로 열었을 때
  http_localhost_8777.indexeddb.leveldb / .blob  ← 로컬 서버로 열었을 때
```

`.blob` 쪽에 이미지 원본이, `.leveldb` 쪽에 나머지 레코드가 들어간다.
다만 LevelDB 내부 포맷이라 **파일 탐색기에서 노트나 이미지를 꺼내 쓸 수는 없다.**
내용을 밖으로 빼는 방법은 아래의 내보내기뿐이다.

## 백업 — 중요

데이터는 **이 브라우저에만** 저장된다. 다른 브라우저·다른 PC에서는 보이지 않고,
브라우저의 "인터넷 사용 기록 삭제"에서 사이트 데이터를 지우면 사라진다.

- 오른쪽 위 `⋯` → **전체 내보내기 (.json)**: 폴더·노트·이미지 전부를 담은 파일 하나로 저장.
  이미지는 이 파일 안에 base64로 함께 들어간다.
- `⋯` → **백업 가져오기…**: 그 파일을 골라 *병합* 또는 *덮어쓰기* 로 복원.
- `⋯` → **현재 노트 내보내기 (.md)**: 노트 한 개를 마크다운 파일로.
- 마지막 백업이 7일을 넘기면 상단에 알림 배너가 뜬다.

정기적으로 .json 백업을 클라우드 드라이브 등에 보관해 두는 것을 권한다.

## 참고

- 일부 브라우저는 `file://` 로 연 페이지의 IndexedDB를 막는다. 그런 경우 앱이 자동으로
  localStorage 저장(약 5MB, 이미지 1.5MB 제한)으로 전환하고 화면에 알린다.
  용량이 걱정되면 이 폴더에서 간단한 로컬 서버를 띄워 `http://localhost` 로 열면 된다.
  예: `python -m http.server 8777` 또는 `npx serve .`
- 시크릿 창에서는 창을 닫을 때 데이터가 사라진다.
- 테마는 처음엔 OS 설정을 따르고, 오른쪽 위 🌙 / ☀️ 로 바꾼 값이 저장된다.
